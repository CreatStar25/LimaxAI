현지시간 9월 8일, OpenAI가 차세대 이미지 생성 모델 **GPT Image 2.5**(ChatGPT Images 2.5)를 정식 출시했습니다. 이전 세대 Images 2.0과 비교하면 이번 업그레이드의 핵심은 '더 예쁘게 그리는 것'이 아니라 '더 편하게 고치는 것'입니다. **생성 속도는 최대 50% 향상되고, 정밀 편집으로 원하는 부분만 바꿀 수 있으며, 여러 차례 수정해도 결과가 흔들리지 않습니다.**

OpenAI는 Sketch 손그림, 창작 템플릿, 이미지 댓글 같은 새 기능도 함께 선보이며 AI 이미지 생성이 전문 디자인 워크플로에 한 걸음 더 가까워졌습니다. 현재 사용자들은 ChatGPT Images와 API의 GPT Image 시리즈를 통해 매주 **30억 장 이상**의 이미지를 생성하고 있습니다.

## 1. 한 부분만 바꾸고 전체는 유지: 정밀 편집이 최대 하이라이트

AI 이미지 생성에서 진짜 골치 아픈 부분은 대개 첫 장을 만든 뒤에 생깁니다. 인물은 만족스러운데 옷만 바꾸고 싶고, 제품은 정해졌는데 배경만 바꾸고 싶고, 포스터는 완성됐는데 한 줄만 고치고 싶을 때 — 기존 모델은 한 곳을 바꾸면 다른 곳까지 함께 바뀌곤 했습니다.

GPT Image 2.5는 **정밀 편집**을 가장 중요한 위치에 두었습니다. 공식 사례인 '전신 편집', '다도시 여행 티켓' 등은 연속 이미지로 수정 과정을 보여주며, 모델이 지시한 부분만 정확히 바꾸면서 원래의 주체·구도·디테일을 유지할 수 있는지에 초점을 맞춥니다.

X 사용자 @thesoragirls의 직접적인 테스트가 이해하기 쉽습니다. 이미지에 촛불을 그리고 꽃잎 하나를 '변경하지 말 것'으로 지정한 뒤 다른 영역을 수정하도록 했습니다. 결과, 고정한 꽃잎은 그대로 남고 다른 부분은 지시대로 바뀌었습니다.

다만 연속 편집이 디테일 문제를 완전히 해결한 것은 아닙니다. 일본 애니메이션 제작 아티스트 @genel_ai의 실측 결과, 편집이 계속 쌓이면 이미지에 계단 현상이나 질감 변화가 생길 수 있다고 합니다. 즉 **2.5는 안정성이 뚜렷하게 개선됐지만, 복잡한 장면에서는 여전히 화질 손실이 남습니다.**

## 2. 참조 이미지가 더 안정적: 모습을 바꿔도 주인공은 그대로

GPT Image 2.5의 두 번째 변화는 **참조 이미지** 처리입니다. 사람·반려동물·제품 사진을 제공하고 새 장면, 시각적 스타일, 구도 변경을 요청하면 새 버전이 주체의 식별 특징을 더 잘 유지하면서 조명과 질감 표현도 개선됩니다.

공식 반려동물 옷입히기 사례를 보겠습니다. 개 사진을 입력하면 모델이 흰색 스턴트맨 의상을 입히는데, 얼굴 특징·털 색·자세, 심지어 배경의 의자와 바닥 빛까지 원본과 대응합니다. **중요한 것은 새 옷이 자연스러운 것뿐 아니라 한눈에 같은 주인공임을 알아볼 수 있다는 점입니다.**

| 참조 이미지 장면 | 확인 포인트 |
| --- | --- |
| 인물 초상 | 장면·스타일을 바꿔도 이목구비가 안정적인지 |
| 반려동물 창작 | 옷을 갈아입혀도 털색·자세·비율이 유지되는지 |
| 제품 장면 | 포장 윤곽·라벨·재질·촬영 각도가 바뀌지 않는지 |

이는 같은 인물·제품·브랜드 소재를 반복해서 쓰는 작업에 특히 중요합니다. API 사용자는 같은 참조 이미지로 여러 버전을 생성해 매번 다시 만들 때 생기던 편차를 줄일 수 있습니다.

## 3. 여러 차례 편집이 더 일관적: 앞서 고친 부분이 남는다

세 번째 수정할 때 첫 번째에서 확정한 디테일이 바뀌어 버리는 것 — 반복 수정에서 가장 효율을 떨어뜨리는 문제입니다. GPT Image 2.5는 **여러 차례 편집의 일관성**을 뚜렷하게 개선해, 이후 수정이 앞선 결과를 이어받아 주체 변형·디테일 드리프트·화질 저하를 줄여줍니다.

OpenAI는 '정육면체 회전', '여행 인포그래픽', '생일 케이크' 세 가지 사례로 시연했습니다. 모두 한 번에 끝나지 않고 여러 차례 연속 수정을 거칩니다. 보여주고자 하는 것은, 앞선 수정이 유지되고 이후 작업이 완성된 내용을 계속 망가뜨리지 않는다는 점입니다.

실제로 제품 홍보 이미지를 만들 때 수정을 몇 단계로 나눌 수 있습니다:

1. **첫 번째는 배경 변경**이며 제품 모양·라벨·배치 각도를 유지합니다.
2. **두 번째는 조명 조정**이며 방금 확정한 배경과 제품 디테일을 유지합니다.
3. **세 번째는 문구 여백 추가**이며 앞선 두 단계의 구도와 조명을 유지합니다.

마지막 점검 때 첫 번째와 마지막을 나란히 비교합니다. 라벨이 바뀌었는지, 재질과 윤곽이 안정적인지, 확정한 배경과 배색이 유지됐는지. **매 수정이 앞선 성과 위에 쌓이는 것, 그것이 여러 차례 편집 일관성의 진짜 가치입니다.**

## 4. 두 가지 모드: 일상은 더 빠르게, 완성본은 더 정밀하게

GPT Image 2.5는 API 측에서 서로 다른 니즈에 맞는 두 가지 버전을 제공합니다:

| 버전 | 포지션 | 적합한 장면 |
| --- | --- | --- |
| **Flare** | 기본 버전, 속도 우선 | 소셜 콘텐츠, 제품 체험, 비주얼 검색, 빠른 프로토타입, 대량 생성 |
| **Sunburst** | 고화질 버전, 정밀도 우선 | 정식 광고 소재, 고품질 제품 이미지, 세밀한 제어가 필요한 작업 |

공식 설명에 따르면 Flare는 이전 세대 GPT Image 2보다 품질이 높으면서 **지연 시간을 50% 줄였습니다**. Sunburst는 더 긴 생성 시간을 허용해 더 높은 편집 정밀도를 얻습니다.

간단한 사용 아이디어: **먼저 Flare로 방안을 빠르게 탐색하고, Sunburst로 최종 이미지를 완성하세요.** 이는 고정된 흐름이 아닙니다. 처음부터 명확한 요구가 있다면 바로 Sunburst를 써도 좋고, 일상 삽화나 아이디어를 빠르게 확인하는 용도라면 Flare가 더 적합합니다.

## 5. 새로운 활용법: 몇 줄 그리면 알아듣는다

모델 자체 외에도 OpenAI는 ChatGPT에 몇 가지 새로운 조작 방식을 추가했습니다:

- **Sketch 손그림**: ChatGPT 안에서 바로 스케치를 그리면 모델이 이를 바탕으로 최종 이미지를 생성합니다. 방을 디자인하려면 레이아웃을, 옷을 만들려면 윤곽을 그리면 됩니다. `@Sketch`를 입력하면 호출할 수 있으며, 텍스트 프롬프트 의존도를 크게 낮춰줍니다. 사물의 위치·비율·윤곽은 말로 설명하기 어렵지만 그리면 직관적이기 때문입니다.
- **Templates 템플릿**: Poster, Merch 같은 자주 쓰는 형식을 추가했습니다. 템플릿을 고르고 정보·요소·스타일을 채우기만 하면 되며, 매번 빈 캔버스에서 시작할 필요가 없습니다.
- **이미지 댓글**: 이미지 위에서 수정할 위치를 직접 표시해 부분 조정을 지정할 수 있습니다.
- **프롬프트 공유**: 이미지를 공유할 때 그 이미지를 생성한 프롬프트를 함께 공유할 수 있어, 받은 사람이 자기 사진으로 바꿔 계속 생성할 수 있습니다.

이 기능들은 '생성 이후'의 워크플로를 채워, 이미지 생성을 일회성 '뽑기'에서 계속 다듬을 수 있는 창작 과정으로 바꿔놓았습니다.

## 6. GPT Image 2.5 사용법: 3단계로 시작하기

이번 업그레이드를 직접 체험하고 싶다면 다음 순서대로 진행하세요:

1. **이미지 생성 입구를 열고** GPT Image 2.5 모델을 선택합니다.
2. **설명을 입력하거나 참조 이미지를 업로드**합니다. 수정이 필요하면 사람·반려동물·제품 사진을 업로드하고 무엇을 바꾸고 무엇을 유지할지 명확히 적습니다.
3. **모드를 선택해 생성**합니다. 먼저 빠른 모드로 몇 가지 방안을 시도하고, 방향이 정해지면 고화질 모드로 최종 디테일을 다듬습니다.

이번 업그레이드가 내 작업에 맞는지 판단하려면 익숙한 이미지로 테스트해 보세요. 이미지 한 장을 업로드하고 명확한 수정 요청 하나를 낸 뒤, 유지할 내용을 적어 둡니다. 점검할 때는 세 가지에 집중하세요 — **대기 시간이 줄었는지, 주체가 그대로인지, 여러 차례 수정 후에도 디테일이 안정적인지.**

## 요약

GPT Image 2.5 이번 업데이트의 초점은 분명합니다. **생성 이후의 수정을 더 쉽게 제어하고, 참조 이미지를 연속 사용해도 안정적으로 유지하며, Sketch·템플릿·이미지 주석을 워크플로에 녹여내는 것.**

| 항목 | 핵심 |
| --- | --- |
| 생성 속도 | 지연 시간 최대 50% 감소 |
| 정밀 편집 | 원하는 부분만, 전체를 망가뜨리지 않음 |
| 참조 이미지 충실도 | 모습을 바꿔도 주인공은 그대로 |
